# Candidate data audit: subject_2-20231022_201316

**Decision:** NO-GO as the primary `place_demo`.

## Inventory

- 828 synchronized frames per camera stream.
- Nine RGB streams: eight at 640×480 and one HoloLens stream at 1280×720.
- Eight depth streams and eight per-frame NumPy label streams.
- 7,452 color images, 6,624 depth images, and 6,624 label files.
- Extracted size: approximately 1.3 GB.

## Why it does not satisfy the benchmark contract

1. It is a multi-camera RGB-D capture rather than one monocular RGB video.
2. The sequence contains several objects and multiple successive rearrangements.
3. No single marked target supports an unambiguous source→target Place trajectory.
4. The HoloLens view is useful but includes the whole multi-object sequence, not one
   clean 10–20 second Place demonstration.

Using this sequence as the headline demonstration would weaken the project's central
claim and make automatic success criteria ambiguous.

## Disposition

The extracted candidate was removed from the project after review. It was not used
for training, evaluation, or reported results.

## Storage

The source TAR and its Windows `Zone.Identifier` sidecar were deleted after verified
extraction. The extracted directory was subsequently moved to the system trash, so
it is no longer present under `data/raw/candidates/`.
